## 最重要的一点：numpy 和线代不是绑在一起的

**别把它们当成一条线。** 看这个划分：

### numpy 基础（不需要任何线代）

| 内容 | 对应线代 |
|---|---|
| 创建数组、`shape`、`dtype` | ❌ 无关 |
| 索引、切片 | ❌ 无关 |
| **逐元素运算、广播** | ❌ 无关 |
| 统计函数、条件筛选 | ❌ 无关 |

**这四块是你前 3 周 numpy 学习的全部内容，一点线代都用不到。**

### numpy 的线代部分（才需要对照）

| 内容 | 对应线代章节 |
|---|---|
| `A @ B` 矩阵乘法 | 第 2 章 |
| `A.T` 转置 | 第 2 章 |
| `np.linalg.det` | 第 1 章 |
| `np.linalg.inv` | 第 3 章 |
| `np.linalg.solve` | 第 4 章 |
| `np.linalg.eig` | 第 5 章 |

**所以：numpy 该学就学，不用等线代。** 两条线是**并行的**，只在上面这 6 个点上交汇。

## ⚠️ 一条必须记住的规则：文件名不能和库重名

**踩过的坑**：把练习文件命名为 `numpy.py`，然后 `import numpy as np` 就报错：

```
AttributeError: module 'numpy' has no attribute 'array'
(consider renaming 'D:\2\py01\numpy.py' if it has the same name as a library you intended to import)
```

### 原因

Python 找库的顺序：

```
① 当前文件夹        ← 你的 numpy.py 在这里，先被找到
② 已安装的库        ← 永远到不了
```

所以 `import numpy` 导入的是**你自己的文件**，而不是真的 numpy 库。

### 危险文件名（绝对不能用）

```
numpy.py      scipy.py       matplotlib.py   pandas.py
random.py     math.py        json.py         os.py
sys.py        copy.py        time.py         re.py
```

### 安全命名（加前缀或后缀）

| ❌ | ✅ |
|---|---|
| `numpy.py` | `numpy第一课.py`、`numpy_练习01.py` |
| `random.py` | `随机数练习.py` |
| `math.py` | `数学练习.py` |

### 自查方法

报错里出现 `module 'X' has no attribute 'Y'`，**而 X 是你自己写过的文件名** → 就是这个问题。

解决：**改名 + 删掉 `__pycache__` 目录**（缓存里可能残留旧的编译结果）。
