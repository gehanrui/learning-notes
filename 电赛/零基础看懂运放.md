## 二、五级阶梯

### 第 0 级：它长什么样（10 分钟）

**目标**：知道运放是个"8 个脚的小黑块"

**做什么**：
1. 打开 `datasheet\lm358_中文.pdf`，**只看第 2 页的引脚图**
2. 看懂这张图的含义：
   ```
   1 脚 ─┐         ┌─ 8 脚
   2 脚 ─┤ LM358   ├─ 7 脚
   3 脚 ─┤ (8脚)   ├─ 6 脚
   4 脚 ─┘         └─ 5 脚
   ```
   **LM358 里面有两个运放**（所以叫"双路"），每个运放占 3 个脚
3. 记住这几个脚的用途（先不用懂为什么）：
   - **2 脚：反相输入（IN−）**
   - **3 脚：同相输入（IN+）**
   - **1 脚：输出（OUT）**
   - **8 脚：正电源（V+）**
   - **4 脚：负电源或地（V−）**

**验收**：能指着图说出"1 脚是输出，2、3 脚是输入，8 和 4 脚是电源"

> **这一级就到这。看不懂的就跳过，后面会解释。**

---

### 第 1 级：它干什么（20 分钟）

**目标**：一句话说清运放的功能

**核心一句话**：

> **运放有两个输入，一个输出。它把"两个输入的差值"放大很多倍。**

写成公式：

```
Vout = A × (V+ − V−)

其中：
  A   = 放大倍数（开环增益，通常是 10万 ~ 100万）
  V+  = 同相输入（3 脚）的电压
  V−  = 反相输入（2 脚）的电压
  Vout = 输出（1 脚）的电压
```

**关键理解**：**它放大的是"差值"，不是"某个电压本身"。**

**这就是"运算放大器"名字的来历**——最早的运放用在模拟计算机里做加减乘除运算。

**做什么**：
1. 运行 `运放入门演示.py`，看那张"放大前后"的图 → **理解为什么要放大**
2. B站搜「**运算放大器 通俗讲解**」或「**运放 入门**」，看 1 个视频（10 分钟左右）

**验收**：能对别人说出"运放放大的是两个输入之间的差值，放大倍数可以几十万倍"

### 第 2 级：算一个具体例子（30 分钟）

**目标**：会算最简单的运放电路

**问题**：运放开环增益是 10 万倍，那输入 1mV 差值，输出就是 100V——**早就烧了**。

**所以实际电路必须加"负反馈"**：把输出接回反相输入端。

**最经典电路：反相放大器**

```
        R2 (反馈电阻)
     ┌────/\/\/────┐
     │             │
Vin ─┴─ R1 ──┬─── (2脚 IN−)  ┌─── Vout
             │                │
            (3脚 IN+) ── 地 ──┘
```

**它的公式（现在先背下来，第 3 级推导）**：

```
Vout = −(R2 / R1) × Vin
```

**负号的意思：输入正的时候，输出是负的（反相）。**

**手算练习**（现在就算，3 分钟）：

| 题 | R1 | R2 | Vin | Vout = ? |
|---|---|---|---|---|
| 1 | 1 kΩ | 10 kΩ | 0.1 V | **−1 V** |
| 2 | 2 kΩ | 10 kΩ | 0.5 V | ? |
| 3 | 1 kΩ | 47 kΩ | 0.02 V | ? |

（答案：题2 = −2.5 V；题3 = −0.94 V。自己先算再看）

**做什么**：
1. 打开 Falstad 仿真器：https://www.falstad.com/circuit/circuitjs.html
2. 菜单 **Circuits → Op-Amps** 里找反相放大器
3. 改 R1、R2 的值，**看输出波形怎么变**
4. 用手算的题 1 对一下：设置 R1=1k、R2=10k、输入 0.1V，看输出是不是 −1V

**验收**：能独立用 `Vout = −(R2/R1)×Vin` 算出一道题，并在 Falstad 里验证

> **这一级做完，你已经超过"零基础"了。** 你能看懂简单的运放电路，也理解了"反馈"这个概念。

### 第 3 级：虚短虚断（40 分钟）

**目标**：理解分析运放电路的两个"作弊公式"

**这是运放最反直觉、也最有用的部分。**

**两个假设**（在负反馈成立时）：

| 名称 | 内容 | 为什么 |
|---|---|---|
| **虚短** | V+ ≈ V−（两个输入端电压几乎相等） | 因为增益极大：输出 = A×(V+−V−)，只要输出是有限值（比如 5V），那 (V+−V−) 必须极小（5V ÷ 10万 = 50μV ≈ 0） |
| **虚断** | 流入两个输入端的电流 ≈ 0 | 因为运放输入阻抗极高（几 MΩ ~ 几 TΩ） |

**用它们推导第 2 级的公式**：

```
反相放大器：
  虚短 → V− = V+ = 0（因为 V+ 接地）
  虚断 → 流过 R1 的电流 = 流过 R2 的电流

  (Vin − V−)/R1 = (V− − Vout)/R2
  (Vin − 0)/R1 = (0 − Vout)/R2
  Vin/R1 = −Vout/R2
  Vout = −(R2/R1) × Vin     ← 推导出来了
```

**做什么**：
1. B站搜「**虚短虚断**」，看 1–2 个视频（这是全国电类学生的共同难点，视频很多）
2. 自己把上面的推导**手写一遍**（不抄，自己推）

**验收**：能不看资料，用虚短虚断推出反相放大器的公式

### 第 4 级：回到 datasheet（这时候才看得懂）

**目标**：看懂参数表里的每一个参数

**现在再打开 `lm358_中文.pdf` 第 6 页的电气特性表**，你会发现：

| 参数 | 现在你懂了 |
|---|---|
| **Input Offset Voltage**（输入失调电压） | 理想情况 V+=V− 时输出应该为 0，但实际有偏差。**这个偏差折算到输入端就是失调电压**（LM358 是 3mV 最大） |
| **Input Bias Current**（输入偏置电流） | "虚断"是理想假设，实际有极小的电流流进输入端 |
| **CMRR**（共模抑制比） | 两个输入"同时"变化时，输出应该不变。CMRR 衡量这个能力。**脑电采集要求 >100dB** |
| **Large Signal Voltage Gain**（开环增益） | 就是第 1 级那个 A |
| **Unity-Gain Bandwidth**（单位增益带宽） | 放大倍数越大，能处理的频率越低。**LM358 是 1.2MHz** |
| **Quiescent Current**（静态电流） | 不干活时耗的电。**300µA/通道**，关系到电池供电能撑多久 |

**验收**：能对着参数表，用自己的话说出 5 个参数的含义

## 四、关键提醒

### ① 不要试图"看懂整份 datasheet"

**68 页里，你只需要那 8 页。** 其余是给不同封装、不同型号、极端工况准备的，**工程师也只查不看**。

### ② 遇到看不懂的，跳过，别卡

**电子学是"螺旋上升"的**：今天看不懂的东西，学完下一层会突然明白。
你第 0 级看不懂"为什么 2 脚叫反相"，第 2 级学完反相放大器就懂了。

**不要在一处耗两小时。**

### ③ 手算比看视频重要

**运放的公式就 3 个**，但你**必须手算几道题**才能记住。
看完视频觉得"懂了"，一算就错——这是全国电类学生的普遍现象。

**电赛训练就是为解决问题而存在的。** 你报名了，就有这个资源。

**你现在"零基础看不懂"，恰恰说明报名是对的**——因为训练会带你从第 0 级开始走。**不报名的话，你可能一年都不会碰元器件。**
