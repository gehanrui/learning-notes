### ⭐ 为什么 CMRR 对生物电信号特别重要（写进报告能加分）

这个逻辑链你要自己走一遍：

1. **人体是一个强干扰环境**：50 Hz 工频、肌电、电极接触噪声
2. 干扰信号往往**同时**出现在所有电极上（这叫"共模"）
3. 而脑电信号是**电极之间的差值**（这叫"差模"）
4. CMRR = 对"共模"的抑制 ÷ 对"差模"的放大
5. **所以 CMRR 越高，抗干扰越强** —— EEG 采集要求 CMRR 通常 > 100 dB

**这段话自己组织语言写，别照抄。** 但它就是你报告里"为什么运放重要"的答案。
