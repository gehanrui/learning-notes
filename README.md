## 项目仓库规范

每个项目仓库必须包含：

1. `README.md` —— 一句话说明做了什么、结果指标是多少
2. `requirements.txt` —— 环境依赖
3. `src/` —— 代码
4. `results/` —— 结果图（混淆矩阵、准确率对比）
5. 复现说明 —— 数据从哪下载、跑哪条命令出结果

**规则：数据不进仓库，结果能复现。**
